🚀 Getting Started

Base URL

http://localhost:5000/api

Authentication

Currently, no authentication is required. All endpoints are publicly accessible.

Request Headers

Header Value
Content-Type application/json

Response Format

All responses are in JSON format with a consistent structure:

{ "success": true, "message": "Description of the response", "data": { /* Response data */ } }

📡 API Endpoints

GET
/todos

Retrieve all todos from the database

Response Example

{ "success": true, "message": "All todos retrieved successfully", "count": 2, "data": [ { "id": 1, "title": "Learn Node.js", "description": "Complete Node.js fundamentals course", "priority": "high", "status": "pending", "createdAt": "2026-05-18T00:00:00.000Z", "updatedAt": "2026-05-18T00:00:00.000Z" } ] }

cURL Example

curl http://localhost:5000/api/todos
GET
/todos/:id

Retrieve a single todo by its ID

Path Parameters

id (integer) - The ID of the todo to retrieve

Response Example

{ "success": true, "message": "Todo retrieved successfully", "data": { "id": 1, "title": "Learn Node.js", "description": "Complete Node.js fundamentals course", "priority": "high", "status": "pending", "createdAt": "2026-05-18T00:00:00.000Z", "updatedAt": "2026-05-18T00:00:00.000Z" } }

cURL Example

curl http://localhost:5000/api/todos/1
GET
/todos/search/query

Search and filter todos by status, priority, or title

Query Parameters

status (string) - Filter by status: pending, in-progress, completed
priority (string) - Filter by priority: low, medium, high
title (string) - Search by title (case-insensitive)

Response Example

{ "success": true, "message": "Todos filtered successfully", "count": 1, "filters": { "status": "pending", "priority": "high", "title": null }, "data": [/* filtered todos */] }

cURL Example

curl "http://localhost:5000/api/todos/search/query?status=pending&priority=high"
POST
/todos

Create a new todo

Request Body

{ "title": "Learn Express.js", "description": "Complete Express.js course", "priority": "high" }

Response Example

{ "success": true, "message": "Todo created successfully", "data": { "id": 3, "title": "Learn Express.js", "description": "Complete Express.js course", "priority": "high", "status": "pending", "createdAt": "2026-05-18T10:35:00.000Z", "updatedAt": "2026-05-18T10:35:00.000Z" } }

cURL Example

curl -X POST http://localhost:5000/api/todos \ -H "Content-Type: application/json" \ -d '{"title":"Learn Express.js","description":"Complete Express.js course","priority":"high"}'
PUT
/todos/:id

Update an existing todo

Path Parameters

id (integer) - The ID of the todo to update

Request Body (all fields optional)

{ "title": "Updated Title", "description": "Updated description", "priority": "low", "status": "completed" }

cURL Example

curl -X PUT http://localhost:5000/api/todos/1 \ -H "Content-Type: application/json" \ -d '{"status":"completed","priority":"low"}'
DELETE
/todos/:id

Delete a todo

Path Parameters

id (integer) - The ID of the todo to delete

cURL Example

curl -X DELETE http://localhost:5000/api/todos/1
GET
/health

Check if the API is running

Response Example

{ "status": "OK", "message": "Todo API is running", "timestamp": "2026-05-18T10:45:00.000Z", "uptime": 1234.56 }
GET
/team

Get team member information

Response Example

{ "success": true, "message": "Team Information", "totalMembers": 4, "team": [ { "name": "Md. Abdul Al Noman", "id": "232031044", "email": "232031044@feniuniversity.ac.bd", "cgpa": 3.69 } ] }
